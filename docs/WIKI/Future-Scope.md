# Future Scope & Roadmap

## 🚀 Future Development Roadmap

ShopSathi AI is built on a modular foundation designed for future expansion and academic research:

### 1. Cloud LLM Integration (Google Gemini API)
* Add server-side Gemini 1.5 / 2.0 Flash integration as an optional intelligence layer for open-domain conversations while preserving deterministic tool execution for transactions.

### 2. Multi-Modal Vision Inspection
* Allow customers to upload photos or short videos of damaged packages directly within the Chat Agent.
* Use vision models to automatically inspect defects, broken seals, or incorrect items to streamline return approvals.

### 3. Multi-Channel Messaging Integrations
* Deploy the ShopSathi conversational engine as an official **WhatsApp Business** and **Telegram** bot.
* Send proactive delivery tracking updates, dispatch notices, and return pickup OTP notifications.

### 4. Live WebRTC Voice Human Handoff
* Enable seamless browser-to-browser voice transfer from the AI Voice Agent to a live Tier 2 customer support supervisor with complete historical chat transcripts.

### 5. Payment Gateway Integration
* Connect live payment providers (Razorpay / Paytm) for real-time UPI and card processing with automated webhook-based order fulfillment.

### 6. Production Database Migration
* Migrate from SQLite to managed PostgreSQL on Google Cloud SQL / Supabase for enterprise concurrent write throughput.
